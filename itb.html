This service enables you to check whether your RDF graph or data model conforms to SEMIC specifications. For each specification, a set of rules is implemented to determine if the relevant SHACL conventions are followed. These rules define constraints on the structure, relationships, and properties within the models. Validation is also available via REST and SOAP APIs to facilitate integration and conformance testing.

The content to validate can be provided as a file, URI, or direct input. Documentation on using the Interoperability Test Bed's (ITB) RDF validator is available here.

More information available on the SEMIC Support Centre regarding the SEMIC specifications. If you would like to stay informed about SEMIC specifications and related tool developments, you can join the mailing list here.
